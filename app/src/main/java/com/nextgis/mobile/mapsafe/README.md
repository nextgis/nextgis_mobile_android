# MapSafe Mobile module

This package mirrors the MapSafe web and QGIS plugin structure.

## Safeguard features

- Anonymise
  - Donut masking
  - Hexabinning
- Encrypt
- Blockchain notarisation

## Access features

- Verify hash from blockchain
- Decrypt
- View

Implementation will be added incrementally while keeping the feature code separate from the core NextGIS activity and fragment classes.
